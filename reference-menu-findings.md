# Reference menu findings

The provided Studio Hub site uses a two-part menu experience. First, an “Our services” section presents a clean 3-column grid of six category cards, with numbered labels, a short description, and a “See menu” action on each card. A segmented “Women’s edit / Men’s edit” switch sits above the cards.

Second, a dark “The full menu” section introduces a compact category-navigation row. Category buttons include Hair & Styling, Hair Colour, Hair Treatments, Spa & Massage, Nails & Beauty, Threading, Skin Care, Waxing, D-Tan & Bleach, Body & Scalp, and Men’s Grooming. Selecting a category changes the visible service list rather than showing every category expanded at once.

Each visible service is a horizontal row with a two-digit number, service name, short supporting copy, price, and an ADD + action. The booking section follows the menu and contains a selected-services summary, staff selector, date, customer fields, time-slot grid, and WhatsApp booking CTA. The reference site’s visible time slots run from 9:00 AM through 8:30 PM, and the full menu uses a dark background to create a visual transition.

For A ONE, adapt this pattern without changing existing service names, prices, Hydra Facial separation, multi-service selection, 3-booking slot capacity, payment mode, WhatsApp handoff, or monochrome luxury branding. A ONE’s existing four top-level categories can become the category-card layer; its existing subsections can become the compact full-menu tabs. The current A ONE menu already has the needed subsection grouping and selection logic, so the main change is presentation and active-category state rather than data or booking behavior.
